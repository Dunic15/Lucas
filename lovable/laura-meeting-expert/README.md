# Laura Meeting Expert

Lovable-generated landing app for Laura, the live AI process expert that joins
meetings, answers from company knowledge, and produces post-meeting follow-up.

## Run locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

This folder is a source copy for the main `Dunic15/Laura` repository. The
original Lovable-connected checkout is kept local at `lovable/lucas-live-expert`
so its editor history is not disturbed.
